## 目标

把 CyberGear 单电机链路从“能动”推进到“可重复、安全、可观测”：形成 Gill 可执行的台架 smoke、soak、fault injection 和安全验收流程。

```

```

## 实现要点 / 约束

- 验证优先级：安全 > 可重复 > 性能 > 动作幅度。
- smoke：enable、低速 position、velocity、小力矩、disable、状态读取。
- soak：200Hz target、10kHz local tick、至少 10-30 分钟单电机稳定运行。
- safety：ttl 过期、CAN timeout、电机断电、超位置、超速度、超力矩、温度/电压异常模拟、急停。
- 所有测试必须记录 seq、applied_seq、last_target_seq、p99 latency、worst case、stale target、timeout、fault。
- 测试脚本必须默认低幅度/低力矩，危险动作需要显式参数。
- 日志不能无限刷屏；周期 summary 和异常 WARN 分开。
- 不允许为了通过测试而关闭安全状态机。

## 验收标准(给 Gill)

- Gill 能按 README 或脚本一键执行 smoke。
- smoke 全绿：电机可安全 enable、动作、disable。
- 停止 target 后，ttl 过期能触发安全降级。
- CAN 断开或电机断电时，系统进入 fault 或 safe state，不继续执行旧命令。
- 超限 target 被 clamp 或拒绝，并有计数。
- 200Hz target + 10kHz local tick soak 中，MotorHealth `reconciles=true` 或能解释不一致原因。
- 报告给出 p99 target apply latency 和 worst case。
- 报告给出 stale target、motor_timeout、motor_fault 计数。
- 急停路径可演示，恢复必须人工操作，不自动回到 active control。
